# GGUF/LENS

纯前端 GGUF 结构检视仪。直接在浏览器里打开本地 `.gguf` 文件，查看头部、带类型的
元数据、张量索引、权重块格式以及原始字节。没有后端，没有依赖，也不会上传文件。

## 快速开始

直接双击 `index.html` 即可，所有解析都走浏览器 File/Blob API。

也可以启动一个本地静态服务器：

```sh
cd tools/gguf-lens
make serve
# 打开 http://127.0.0.1:8766/gguf-lens/
```

`make serve` 从 `tools/` 根目录提供页面，以便复用 `tools/wave-deck` 下的像素字体；
如果脱离仓库单独复制本工具，字体加载失败时会自动回退到系统等宽字体，功能不受影响。

## 能看什么

- **概览**：文件身份、架构参数、参数总量、平均位宽、文件分段地图、量化类型构成、
  词表摘要、最大张量，以及对齐 / 越界 / 偏移诊断。
- **元数据**：全部 13 种 GGUF 元数据值类型，保留 key、类型、字节区间和完整值。
  数组可翻页、搜索；`tokenizer.ggml.tokens` 会额外显示 GPT-2 byte-level 解码文本，
  中文也可直接搜索。
- **张量**：按名称、类型过滤和排序；显示形状、元素数、块数、原始偏移、绝对数据区间、
  GGML 轴步长与量化块布局。
- **权重预览**：按需切片读取张量，反量化最多 256 个值，展示范围、均值、热力图和
  数值表。
- **分块字节**：按量化块查看真实字节布局，标出块坐标（`row / group`）、字段边界、
  scale 数值、符号位网格与反解码结果。Q1_0 的 128 个符号位会逐字节、逐 bit 展开。
- **带注解的十六进制**：查看原始字节或文件结构时，属于已知张量的字节会按块字段着色，
  悬停可看到块号、字段和块内偏移。
- **文件结构**：头部字段、每个分段的起止偏移与占比，以及可跳转、可翻页的十六进制视图。
- **格式手册**：GGUF 文件布局、头部与索引项语法、元数据类型表、张量类型表，并在载入
  文件后高亮实际使用的类型。

载入时只顺序读取文件头、元数据和张量索引，不把整个权重区读进内存。张量预览与十六进制
视图按需通过 `Blob.slice()` 读取。237 MiB 的 Qwen3 测试文件只解析到约 5.8 MiB 头/索引数据。

## Q1_0 是怎么排布的

Q1_0 的存储单位是 **18 字节的块**，每个块编码 128 个权重。块内顺序固定为：

```text
+0      +1   +2                                               +17
[ d (FP16, 2 B) ][ qs: 16 B = 128 个符号位，LSB-first            ]
```

不是“整个张量先放完所有 FP16 scale，再放所有 bit”。每个块自带一个 scale，块之间首尾
相接；block 0 在 +0，block 1 在 +18，以此类推。符号位从每字节的 bit0 开始映射到较小
的元素下标，`1 → +d`，`0 → -d`。对于二维张量 `[ne0, ne1]`，一行的 `ne0` 维先按
`ne0 / 128` 个块连续存放，然后才进入下一行。

这些信息可以在「张量 → 分块字节」和「格式手册」的 Q1_0 示例里直接对照真实文件查看。

## 支持范围

- GGUF v2 / v3，小端（little-endian）。
- 可数值预览：`F32`、`F16`、`BF16`、`F64`、`I8`、`I16`、`I32`、`I64`、
  `Q4_0`、`Q4_1`、`Q5_0`、`Q5_1`、`Q8_0`、`Q8_1`、`Q2_K`、`Q3_K`、`Q4_K`、
  `Q5_K`、`Q6_K`、`Q8_K`、`IQ4_NL`、`Q1_0`、`Q2_0`、`TQ1_0`、`TQ2_0`、
  `MXFP4`、`NVFP4`。
- 其他 IQ 类型及未知类型仍会显示索引、大小与原始字节（在可确定区间内），但不做反量化。
- v1 已过时且编码不同，当前会明确拒绝；大端文件同样不在支持范围内。
- 预览只解码文件中的原始块结构，不执行矩阵运算，也不会写回文件。

## 测试

```sh
cd tools/gguf-lens
make test
```

测试不需要第三方依赖，覆盖：合成 GGUF 的头部 / 元数据 / 索引解析、布局与统计、
按需切片、拒绝非法版本与截断文件、块字段长度校验，以及 Q1_0 / Q2_0、Q4 / Q5 /
Q6 / Q8、K-quant、TQ、MXFP4 / NVFP4 等参考向量的逐值反量化和 Q1_0 的位序。
